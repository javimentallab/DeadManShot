# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub: [Report a vulnerability](https://github.com/javimentallab/DeadManShot/security/advisories/new).

Say what you found, how to reproduce it and which version you used. English or Spanish are both fine.

This project has a single maintainer, so replies are best effort. I aim to answer within 14 days.

## What counts

Anything that fires the switch when it should not, or keeps it from firing when it should; anything that runs on the computer something other than what the user configured, or reaches files outside the paths the user chose; and anything that leaks the mail or SSH password, the email or the heart-rate data.

## Supported versions

Only the latest release gets security fixes.
